# Инструкция по работе

## Третье задание: 

1. `git clone https://github.com/vladislavpetrov4311/vk_recponse/ -b for_vk_respons`
2. `cd vk_recponse/3_task` Переходим в директорию с docker-compose файлом
3. `docker-compose up` Запускаем файл конфигурации развёртывания
